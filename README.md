Universidad Pedagógica y Tecnológica de Colombia — Seccional Sogamoso

## Integrantes
- Julian Leonardo Arias Pita
- Juan Esteban León Cárdenas

## Descripción
PWA para la gestión digital de créditos académicos (servicio de restaurante) en la UPTC Seccional Sogamoso.

## Stack Tecnológico
- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Node.js + Express
- **Base de datos:** PostgreSQL
- **Contenedores:** Docker + Docker Compose
